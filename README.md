# FluentWasm

FluentUI 5.0 Blazor WebAssembly Standalone App + ASP.NET Core 10 Web API + PostgreSQL

## About The Project

FluentWasm is a Clean Architecture Solution for Blazor Webassembly Standalone App built with FluentUI Components.

### Tech Stack

- Brackend
	- MailKit
	- Microsoft.AspNetCore.Authentication.JwtBearer
	- Microsoft.AspNetCore.Identity.EntityFrameworkCore
	- Microsoft.AspNetCore.Identity.UI
	- Npgsql.EntityFrameworkCore.PostgreSQL
	- MimeKit
	- Serilog
	- AutoMapper
	- FluentValidation
	
- Frontend
	- FluentUI 5.0 <a href="https://www.fluentui-blazor.net/">Watch it here!</a>
	- Blazor WebAssembly Standalone App
